从管理台到线上网站

  1. 导入 Markdown 后，文章会先保存为本地草稿。
  2. 可以在管理台预览、修改标题、日期、分类、标签、摘要和正文。
  3. 确认效果无误后，再点击“发布到网站”。
  4. 发布完成后，文章会自动进入首页、分类、标签、归档和搜索。

发布功能通过独立的 OAuth 后端完成，GitHub Token 只保存在服务端会话中，不会写入浏览器或公开网页。
